# Product Overview

Three Doors is a job-search workspace for people who want to organize opportunities, target roles, professional contacts, application materials, and outreach in one place. Its workflow is built around pursuing a role and building relevant relationships at the company, not just recording an application.

The current interface is especially focused on product-management openings, while profile and CV tools support broader job-search and career-change workflows. The repository does not establish an exclusive target audience or a formal positioning decision.

## The User Journey

1. Add job-board sources and search preferences, or enter an opening manually.
2. Review openings and move the ones worth pursuing into Roles.
3. Track an application and contacts connected to each role: a hiring manager, a recruiter, and someone in another department.
4. Keep contact status and notes current, then use editable message templates for outreach.
5. Maintain a career profile and master CV, tailor materials to a specific job, and review the output before using it.
6. Use Analytics to review progress based on the contact statuses recorded in the product.

Three Doors helps organize and prepare this work; it does not apply for jobs or send outreach messages on the user's behalf.
