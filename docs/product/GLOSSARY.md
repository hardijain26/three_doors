# Glossary

| Term | Plain-language meaning |
|---|---|
| Opening | A job listing discovered from a saved source or entered by the user. See [Features and limits](FEATURES.md). |
| Role | A job the user has decided to pursue and is tracking. See [Features and limits](FEATURES.md). |
| Contact | A person associated with a target role, such as a hiring manager, recruiter, or someone in another department. |
| Outreach | A connection request or follow-up message the user prepares and sends outside Three Doors. |
| Source | A job-board page the user has saved for opening searches. |
| Fit | The user's or system's indication of how closely an opening matches the saved search profile. It is not a hiring prediction. |
| Career path | The user's saved history of roles and experience, used as context for profile and CV workflows. |
| Master resume | The editable resume from which job-specific CV versions can be prepared. |
| API key | A credential that lets Three Doors make AI requests using the user's provider account; the provider bills that account. |
| Provider | The external AI service selected for an AI request, such as OpenAI, Anthropic, or Google Gemini. |
| Browser-only storage | A key-storage option where the key is kept in the user's browser rather than saved as encrypted server data. |

For how these concepts fit together, see the [product overview](OVERVIEW.md) and [features and limits](FEATURES.md).
